# Видеозаписи курса

`manifest.json` сопоставляет 12 уроков с файлами в папке владельца:
https://drive.google.com/drive/folders/10QrEjwibyZQt4iQQ1C4spx9a1gpqBa-T

Каждая запись встроена в соответствующую страницу `lessons/NN.html#video` через Google Drive `/preview`. Ссылка `/view` под плеером открывает ту же запись отдельно. Видеоархив `index.html` ведёт к этим страницам и не загружает все 12 плееров одновременно.

Сами MP4 хранятся в Google Диске. Ссылки должны оставаться доступными для просмотра посетителям сайта. При замене записи обновите её `drive_id`, `view_url` и `embed_url` в манифесте, затем запустите `python connect_drive_videos.py` из корня репозитория.
