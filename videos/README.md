# Видеоархив курса

Эта папка предназначена для локальных видеозаписей курса. Страницы уроков уже настроены на встроенное воспроизведение файлов из этого каталога.

Ожидаемые имена файлов:

- `lesson-01.mp4` — `lesson-12.mp4`
- `supplement-03.mp4`
- `supplement-09.mp4`

Сейчас в исходном архиве сайта присутствуют только закрытые ссылки на Telegram-сообщения; самих видеофайлов в нём нет. Поэтому плеер показывает честный статус до загрузки соответствующих MP4/WebM-файлов и не подменяет локальное видео внешней ссылкой.
